## 🔧 Common Issues and Fixes

❌ **Issue:** The script fails to inject into the game.
**Solution:** Run the script as Administrator (Windows) or grant Accessibility permissions (macOS). Ensure the game is running in Windowed or Borderless mode.

❌ **Issue:** Auto-Farm stops working after a few minutes.
**Solution:** Check your internet stability and ensure the game client is not minimized to the system tray.

❌ **Issue:** "Patience Mode" causes the script to miss important timings.
**Solution:** Adjust the delay sensitivity in the settings. If issues persist, disable Patience Mode and toggle it back on.

❌ **Issue:** The UI overlay is not visible.
**Solution:** Press the toggle hotkey (default: `Insert`) to refresh the overlay. Ensure you are running the script on the same monitor as the game.

❌ **Issue:** Out of Memory error.
**Solution:** Restart the game and script. Clear the game's cache folder.

❌ **Issue:** Script says "Game Version Mismatch".
**Solution:** Wait 24-48 hours for an update, or check for an emergency patch in the repository.

❌ **Issue:** Android APK won't install.
**Solution:** Ensure "Install Unknown Apps" is allowed for your file manager and that no previous version is already installed.
